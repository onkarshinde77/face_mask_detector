[INTRO - 0-10 seconds]

Hi everyone! Let me show you something I've been building - an AI-powered Face Mask Detection System that can identify in real-time whether people are wearing masks or not.

---

[PROBLEM STATEMENT - 10-25 seconds]

During the pandemic and beyond, detecting mask compliance became crucial for public health and safety. But manually checking each person was time-consuming and unreliable. That's where AI comes in.

---

[PROJECT OVERVIEW - 25-45 seconds]

I developed an end-to-end machine learning system that does exactly this. It uses deep learning models to:

First, detect all human faces in an image or video with high accuracy using a Caffe DNN SSD model. Then, it classifies each face to determine whether they're wearing a mask or not. The system achieves 98% accuracy in face detection and 95% accuracy in mask classification.

---

[KEY FEATURES - 45-65 seconds]

What makes this project special?

One - it's MULTI-MODAL. You can upload a static image, process video files, use your webcam for live streaming, or even capture photos directly from your camera.

Two - it's REAL-TIME. The system processes frames instantly, making it perfect for surveillance and monitoring applications.

Three - it's PRODUCTION-READY. I've built a complete web interface using Flask where users can easily interact with the system. The interface is responsive, mobile-friendly, and includes detailed detection statistics.

---

[TECHNICAL STACK - 65-80 seconds]

On the technical side, I used:

- TensorFlow and Keras for building and training deep learning models
- OpenCV for image and video processing
- Flask for the web application
- Modern HTML, CSS, and JavaScript for the frontend
- Containerized with Docker for easy deployment

---

[CAPABILITIES SHOWCASE - 80-110 seconds]

The system can handle multiple scenarios:

For images - upload a photo, and it instantly detects all faces and highlights who's wearing a mask with a green box and who isn't with a red box. Each prediction includes a confidence score.

For videos - process uploaded video files or stream live from your webcam. The system analyzes each frame in real-time, giving you immediate feedback.

The web interface also provides:
- Detailed statistics about detection results
- Color-coded bounding boxes for easy visualization
- Secure file upload handling
- Fast responses even on slower devices
